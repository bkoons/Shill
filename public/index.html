🚀 Self-Host in 3 Steps

Runs anywhere Python 3.10+ is installed. Raspberry Pi, old laptop, VPS, or your daily driver.

1

Clone the Repository

git clone https://github.com/bradk/Shill.git && cd Shill

2

Run the Unified Start Script

./start.sh — auto-creates virtualenv, installs dependencies, launches node. No Docker required.

3

Open the Web UI

Navigate to http://localhost:8000. UDP mesh on :9999. OpenAI-compatible API on /v1/chat/completions.

The full interactive UI (bot chat, 3D swarm, DEX, shield) runs on your local node.
