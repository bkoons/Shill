Connect Distilled LLM to Local Apps

Use Shill in Cline, LM Studio, Jan, Ollama, vLLM, Cursor, or Continue.dev

💡 Standard OpenAI Compatibility: Shill exposes a local endpoint on port 8000. Any application supporting custom OpenAI endpoints or local GGUF models connects without third-party cloud subscriptions.
Cline / Roo Code (VS Code Extension)
In Cline Settings (⚙️), set API Provider to OpenAI Compatible:
Base URL: http://127.0.0.1:8000/v1
API Key: shill-citizen-free
Model ID: shill-mind
LM Studio (Connect as Local Client or Preset)
Option A: Connect LM Studio's Chat or Playground to Shill's local server:
Endpoint: http://127.0.0.1:8000/v1
Model ID: shill-mind
Option B: Load the exported GGUF model into LM Studio:
Export preset generated at: training/lmstudio_preset.json
Jan Desktop (jan.ai)
Connect Jan via custom OpenAI engine or direct model folder:
OpenAI URL: http://127.0.0.1:8000/v1
Model Name: shill-mind
To import into Jan's local model folder (`~/.jan/models/`):
Manifest created at: training/jan_model.json
Ollama CLI & WebUI
Register the distilled debate knowledge directly into Ollama:
# 1. Distill datasets and Modelfile (or click Distill Model in footer):
curl -X POST http://127.0.0.1:8000/api/export/dataset

# 2. Build local Ollama model from the distilled Modelfile:
ollama create shill-mind -f ./training/Modelfile

# 3. Run prompt in terminal:
ollama run shill-mind "How do specialist bots defend against corporate bias?"
vLLM High-Throughput Inference Server
Serve or proxy through vLLM using the distilled weights or proxy:
# Run vLLM with fine-tuned LoRA weights generated by Shill:
python3 -m vllm.entrypoints.openai.api_server \
  --model unsloth/llama-3.2-3b-instruct \
  --enable-lora \
  --lora-modules shill-mind=./training/shill_lora \
  --port 8001
Or simply proxy vLLM-compatible clients to Shill's endpoint: http://127.0.0.1:8000/v1 with model shill-mind.
